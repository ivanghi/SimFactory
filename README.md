# Factory Game

A factory building game built with Vite, TypeScript, and React.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Run tests:
   ```bash
   npm run test
   ```

4. Type check:
   ```bash
   npm run typecheck
   ```

5. Lint:
   ```bash
   npm run lint
   ```

## Project Structure

- `src/data/` - Pure data files (resources, buildings, recipes, milestones)
- `src/sim/` - Simulation logic
- `src/save/` - Save/load functionality
- `src/render/` - Rendering code
- `src/ui/` - User interface components
- `src/main.ts` - Main game loop
